# 实际测试记录

测试日期：2026-10-23。

## 编译

- Windows Dev-C++ TDM-GCC 9.2.0：C++11、`-Wall -Wextra -pedantic` 编译成功，无警告，生成静态链接的 `student_grades.exe`。
- Windows Qt MinGW GCC 13.1.0：C++11、`-Wall -Wextra -Werror -pedantic` 编译成功，无警告。
- CMake 3.30.5 + MinGW Makefiles + GCC 13.1.0：配置及构建成功，生成的程序也通过全部 10 组测试。

## 范围及限制

程序功能无已知未解决问题。数据按实验要求保存在内存，退出不持久化。Windows 程序自动采用 UTF-8 控制台代码页；建议使用支持中文的终端字体。Linux/macOS 和 MSVC 构建未实际执行。

## PowerShell 中文乱码修复验证
